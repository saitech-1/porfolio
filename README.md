# Sai Zay — 3D Portfolio

A premium minimalist portfolio built with React, Vite, Tailwind CSS and React Three Fiber.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- Three.js / React Three Fiber / Drei
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Customize

Main content:
- `src/App.tsx`

3D scene:
- `src/components/Scene.tsx`

Global styling:
- `src/index.css`

The 3D hero is intentionally asset-free, so it loads fast and does not require external HDRIs, textures or model files.
